## 1. Mục tiêu và phạm vi

- **Vấn đề:** câu về Huế mà kho không có (quán phở Hà Nội ở Huế, phòng gym, nha khoa, khách sạn cụ thể…) hôm nay chỉ nhận câu từ chối. C189 / B6 nháp: 15 câu loại này (ăn uống 5, giờ / vé / giá 4…).
- **Trong phạm vi (spec §5 B6, không đổi):**
  - cổng web do **code** mở **sau** câu trả lời kho, chỉ khi câu trả lời đúng bằng câu từ chối chuẩn;
  - truy vấn do code dựng từ câu hỏi lượt này;
  - Serper ≤ 5 kết quả;
  - **một lần gọi model riêng** (không công cụ, không lịch sử) viết mục "Từ web" trích `[w n]`;
  - link + nhãn do code dựng;
  - mục web bị cắt khỏi lịch sử.
- **Thêm (A giao 05/11):** câu khách sạn / lưu trú cụ thể ⇒ đi web, **không nói giá phòng** (backlog Phase 11 (c)); ca "ở Huế có quán phở Hà Nội nào ngon" (có sẵn W01).
- **Ngoài phạm vi:** mở URL / đọc trang (không công cụ mở URL — rào 2); câu ngoài Huế (giữ từ chối + gợi ý B142 — User 03/11); sự kiện theo ngày (Phase 11); link đặt phòng (Phase 11 (b)).
